Инструкция по импорту списка налоговых органов

1) Скопируйте файл Excel (например, `tax_org.xlsx`) в корень проекта или укажите путь.

2) Запустите команду управления Django для конвертации в JSON:

```
python manage.py import_tax_offices path/to/tax_org.xlsx
```

По-умолчанию результат будет записан в `backend/organization/data/tax_offices.json`.

3) SPA может получить список налоговых органов через API (требуется авторизация):

`GET /api/organization/tax-offices/?q=часть_кода_или_наименования`

Ответ: массив объектов `{ "code": "...", "name": "..." }`.

Примечание: команда удаляет пустые строки и дубли по коду.
